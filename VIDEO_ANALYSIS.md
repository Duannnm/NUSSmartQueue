# Video Interface Analysis

## Key Design Elements from Reference Video

### 1. Header Design
- **Logo**: NUSmartQueue with fork/knife icon on the left
- **Tagline**: "Smart canteen recommendations" 
- **Status Indicators**: Online status (green dot), Location found, Refresh button, Logout
- **Clean Layout**: Minimal header with essential information

### 2. Welcome Section
- **Personalized Greeting**: "Welcome back, keithloh00!"
- **Description**: "Here are your personalized canteen recommendations based on queue times and bus schedules."

### 3. Statistics Cards (Top Row)
Four key metric cards in a row:
- **Open Canteens**: Fork/knife icon, number "8"
- **Avg Queue Time**: Clock icon, "7m" 
- **Nearby Canteens**: Location pin icon, number "8"
- **Bus Stops**: Bus icon, number "0"

### 4. Filters Section
- **Title**: "Filters & Preferences" with filter icon
- **Action**: "Show Filters" button on the right

### 5. Canteen Recommendations Section
- **Title**: "Canteen Recommendations"
- **Card Layout**: Large cards for each canteen with detailed information

### 6. Canteen Card Design
Each canteen card includes:
- **Header**: Canteen name + "Best Match" badge (for top recommendation)
- **Location**: Building and level information
- **Cuisine Tags**: Small pills for cuisine types (Chinese, Malay, Indian, etc.)
- **Score**: Large red number on the right (0-100 scale)
- **Metrics Row**: 4 key metrics with icons:
  - Total time (clock icon): "9m total" with breakdown
  - People count (person icon): "3 people" with crowd level
  - Walking time (location icon): "4 min walk" with distance
  - Price (star icon): "$4.5 Average price"
- **Status Tags**: Green pills for "Short queue", "Very close", "Not crowded"
- **Operating Info**: Hours and amenities (WiFi, Study area, etc.)
- **Action Button**: Black "View Details" button

### 7. Right Sidebar
- **Nearby Bus Arrivals**: Section for bus information (to be excluded)
- **About NUSmartQueue**: Information section with features list

### 8. Color Scheme
- **Background**: Light gray/white
- **Cards**: White with subtle shadows
- **Primary Color**: Green for positive indicators
- **Secondary**: Red for scores/important numbers
- **Text**: Dark gray for readability
- **Accent**: Blue for interactive elements

### 9. Typography
- **Headers**: Bold, larger font sizes
- **Body Text**: Clean, readable font
- **Numbers**: Prominent display for metrics
- **Tags**: Small, rounded pills

### 10. Layout Structure
- **Main Content**: Left side with full-width canteen cards
- **Sidebar**: Right side with additional information
- **Responsive**: Clean grid layout
