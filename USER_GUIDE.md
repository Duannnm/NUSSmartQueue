# NUS Smart Queue - Enhanced User Guide

## Welcome to NUS Smart Queue Enhanced Edition

This guide will help you navigate and make the most of the enhanced NUS Smart Queue application with its new MS3 features including advanced location services, intelligent recommendations, and comprehensive analytics.

## Getting Started

### Accessing the Application

1. **Open the Application:** Navigate to the NUS Smart Queue web application
2. **Choose Your Role:** Select either "I'm a Student" or "I'm a Vendor"
3. **Demo Access:** Use the quick demo buttons for instant access with sample data

### Demo Accounts
- **Student Demo:** Experience all student features with realistic campus data
- **Vendor Demo:** Access the complete vendor dashboard with analytics

## For Students

### 1. Smart Recommendations Tab

#### Quick Picks
The application automatically provides four instant recommendations:
- **Closest:** Nearest stall based on your location
- **Fastest:** Shortest estimated wait time
- **Least Crowded:** Minimum queue length
- **Best Rated:** Highest customer rating

#### Detailed Recommendations
Each recommendation includes:
- **Smart Score:** Overall recommendation score (0-100)
- **Distance & Walking Time:** Precise location data
- **Wait Time:** Real-time estimated wait
- **Crowd Level:** Current queue status (low/medium/high)
- **Recommendation Text:** Personalized suggestion
- **Score Breakdown:** Detailed factor analysis

#### Using Filters
- **Max Distance:** Set your preferred walking distance
- **Max Wait Time:** Filter by acceptable wait time
- **Sort Options:** Choose from smart score, distance, wait time, or rating

### 2. All Stalls Tab

#### Comprehensive Stall View
- **Grid Layout:** Visual cards for each stall
- **Key Information:** Rating, category, price range, queue status
- **Real-time Data:** Current queue length and estimated wait time
- **Distance Information:** Walking distance and time

#### Filtering and Sorting
- **Category Filter:** Western, Asian, Local, Healthy, Japanese, Indian
- **Sort Options:** Smart score, wait time, queue length, distance, rating, name
- **Status Indicators:** Color-coded crowd levels

### 3. Location Services Tab

#### Advanced Location Features
- **Indoor Positioning:** Precise location within buildings (5-10m accuracy)
- **Nearby Canteens:** Automatic detection of dining options
- **Walking Directions:** Accurate time and distance calculations
- **Real-time Updates:** Continuous location monitoring

#### Location Information
- **Current Position:** Your exact campus location
- **Nearby Options:** Canteens within walking distance
- **Navigation Help:** Directions to selected stalls

### Tips for Students

1. **Enable Location Services:** Allow location access for personalized recommendations
2. **Check Quick Picks:** Start with instant recommendations for fast decisions
3. **Use Filters:** Customize recommendations based on your preferences
4. **Monitor Crowd Levels:** Choose low-crowd options for faster service
5. **Plan Ahead:** Check wait times before heading to canteens

## Troubleshooting

### Common Issues and Solutions

#### Location Not Working
1. **Check Permissions:** Ensure location access is enabled
2. **Refresh Page:** Reload the application
3. **Check Connection:** Verify internet connectivity
4. **Browser Settings:** Enable location services in browser

#### Recommendations Not Loading
1. **Wait for Location:** Allow time for position detection
2. **Check Filters:** Verify filter settings aren't too restrictive
3. **Refresh Data:** Reload the page for updated information

#### Analytics Not Displaying
1. **Check Connection:** Ensure stable internet connection
2. **Refresh Dashboard:** Reload the analytics tab
3. **Clear Cache:** Clear browser cache if needed

#### General Performance Issues
1. **Close Other Tabs:** Free up browser resources
2. **Update Browser:** Use the latest browser version
3. **Check Internet:** Verify stable connection
4. **Restart Application:** Refresh the page completely
